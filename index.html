Dayflow

Drop in a chat message, a screenshot, a PDF or a voice note. Dayflow reads it and turns it into events, tasks and reminders, on the web and in a native Android app.

How Dayflow grew

From a web demo to an app that can see your screen.

  2. 25 Sep

    The web demo

    React and Gemini. Paste anything, watch the dashboard and a phone simulator fill up together.

  3. 12 Nov

    1.0 Native Android

    Kotlin and Jetpack Compose, with a local Room database and the share sheet.

  4. 12 Nov

    1.1 Screen Intelligence

    Reads notifications and what is on screen, so it knows the context of your day.

  5. 12 Nov

    1.2 System overlay

    New insights pop up over whatever app you have open.

  6. 13 Nov

    1.3 Screen agent

    It can tap, scroll and go back for you. Banking and login apps are never touched.

  7. Next

    More AI providers

    Not only Gemini, plus a server-side proxy so no key sits in the browser.
