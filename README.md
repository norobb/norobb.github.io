# norobb.github.io

My personal site: who I am, Untis Neo, Dayflow, and 3D shapes you can spin, a scroll-driven 3D phone and physics blocks.

Plain HTML, CSS and JavaScript, no build step. GitHub Pages serves the `main` branch as it is.

- `index.html`: the page
- `style.css`, `tokens.css`, `base.css`: styles (colours and fonts live in `tokens.css`)
- `hero3d.js`: the three.js hero scene
- `main.js`: scroll effects, marquee, physics toybox, tilt
- `images/`: app screenshots

Preview locally: `python3 -m http.server` and open http://localhost:8000
